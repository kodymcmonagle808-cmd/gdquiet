# GD Quiet

Automatically mutes all background applications (YouTube, Discord, Spotify, etc.) when your level progress passes a chosen percentage in Geometry Dash, and unmutes them when you die, restart, leave the level, or close Geometry Dash.

## Installation & Setup

1. Download `gd-mute-mod.zip` and `gdmute.exe` from the Releases page.
2. Unzip the mod. Put the `.geode` file in GD's mods folder (in GD, open the Geode menu and use the folder button), then restart GD.
3. Run `gdmute.exe` before starting GD and leave it running.
4. Change the mute point in the mod's settings in the Geode menu (default: 50%).
5. Windows only. Windows may warn about an unsigned exe.

## Known Limitation

Unmuting also unmutes apps that you had previously muted by hand in Windows Volume Mixer.
