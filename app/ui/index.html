    Setup & troubleshooting
    1.
    Open Discord Keybinds

    In Discord, open User Settings → Keybinds.

    2.
    Bind Toggle Deafen

    Create a keybind with action Toggle Deafen (not Toggle Mute), such as Ctrl+Shift+D or F8.

    3.
    Match the hotkey above Needs hotkey

    Turn on auto-deafen, click Record, and press the exact same key combination.

    4.
    Test in a voice channel

    Join a voice call and click Test to confirm Discord toggles between deafened and undeafened.

    Test hotkey does nothing in Discord

    Verify Discord's keybind action is set to Toggle Deafen and enabled. If Discord runs as Administrator, run GDQuiet.exe as Administrator too. Avoid keys captured by other overlays.

    Discord toggles backwards (deafens on death)

    Start the level undeafened. GD Quiet sends the toggle once when crossing your threshold and once again on death, exit, or 100%.

    Muting apps without Discord hotkeys

    Use the Apps to mute tab to control Chrome, Spotify, or Discord volume directly via Windows audio sessions.

    Restore behavior
    Discord undeafens automatically when:
    • You die or exit the level
    • You reach 100% (when enabled)
    • You click Unmute & undeafen all
    Before every run: Start undeafened so the first toggle deafens and the end-of-attempt toggle restores voice audio. Avoid Space, Up, W, or Esc as hotkeys.

    Set up the Eclipse label
    1. Install the Eclipse mod menu with Geode.
    2. In Geometry Dash, press Tab to open Eclipse.
    3. Open Labels and choose Add new label.
    4. Type {levelName} ({levelID}) as the label text.
    5. Play a level. The name and ID appear on the left side of the screen and GD Quiet picks them up.
    The ID matters because many levels share a name (like startpos copies). With an ID in the label, GD Quiet matches the ID and ignores the name. {levelName} on its own still works. Levels are read even while muting is paused.
    Label box

    By default GD Quiet reads the left 30% of the game window. Drawing a box tightly around the level-name label is the most reliable.
