2. HOW GD QUIET WORKS & LOCAL-ONLY PROCESSING
--------------------------------------------------------------------------------
GD Quiet is a standalone Windows desktop utility designed to reduce background
distractions while playing Geometry Dash. When active, the Software:
  (a) Captures only the configured target window band (default: top 10% of
      GeometryDash.exe) or a user-selected screen region using Windows screen
      capture APIs.
  (b) Runs local Windows Optical Character Recognition (Windows.Media.Ocr)
      in memory to detect your current level percentage.
  (c) Uses the Windows Core Audio Session API (WASAPI) to mute and unmute only
      the specific Windows applications you explicitly select.
  (d) Optionally sends your configured keyboard shortcut ("Toggle Deafen")
      to Discord when your percentage crosses your chosen threshold, and sends
      it again to undeafen upon death, level exit, or 100% completion.
  (e) Optionally reads the level name and level ID from a level label you add
      in the Eclipse mod menu, using the same local OCR, to load your
      per-level settings.

All screen capture, OCR text recognition, audio session control, and settings
storage occur locally on your Windows PC.


3. PRIVACY
--------------------------------------------------------------------------------
GD Quiet does NOT collect, transmit, or sell:
  - Gameplay video, screenshots, or OCR text (these never leave your PC);
  - Audio streams, microphone input, or Discord voice/chat data;
  - Analytics, usage tracking, or crash telemetry.

Your preferences are stored in your local Windows AppData folder
(%APPDATA%\GDQuiet\config.json) and can be deleted or reset at any time.

Optional Discord sign-in: if you choose "Sign in with Discord", sign-in happens
in your web browser through Supabase (the service that hosts GD Quiet's
accounts). GD Quiet then stores your sign-in session on this PC, encrypted to
your Windows user account (%APPDATA%\GDQuiet\session.bin). While you are
signed in, your saved levels (level names, level IDs, thresholds, which apps
each level mutes, and capture settings) are synced to your account so they can
be shared between your PCs. Only you can access your synced levels. Your
Discord username and avatar are shown in the app. Sign out at any time to stop
syncing and remove the session from this PC.


4. NETWORK ACCESS
--------------------------------------------------------------------------------
GD Quiet makes these network requests:
  - Update checks against the GitHub Releases API for this project, and
    downloading GDQuiet-Setup.exe when you choose to install an update. You
    can turn off automatic update checks in Settings. Before installing an
    update, GD Quiet verifies the file size and SHA-256 checksum.
  - Only if you sign in with Discord: sign-in and level sync requests to
    GD Quiet's Supabase project, and loading your Discord avatar image.
  - The optional OBS overlay runs a web server on your own PC only
    (127.0.0.1); it is not reachable from other computers.


5. USER RESPONSIBILITY & SYSTEM CONFIGURATION
--------------------------------------------------------------------------------
You are solely responsible for:
  - Selecting which applications GD Quiet is permitted to mute;
  - Configuring your Discord Toggle Deafen keybind and mute threshold safely;
  - Verifying that Geometry Dash is running in Windowed or Borderless mode
    with "Show Percentage" enabled (or configuring a custom screen region);
  - Ensuring that automated keybinds do not conflict with other software.

Always test your configuration using the built-in 30-second Screen Test or
the "Unmute & Undeafen All" safety button if you notice unexpected audio state.
